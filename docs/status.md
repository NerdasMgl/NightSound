# 夜莺 App 状态（0.2.2）

## 0.2.0 相对 0.1.0 的改动（对应第二轮反馈的 4 点）
1. **新手引导与导航**：首次打开走 5 步引导（它是什么 → 手机怎么放 → 麦克风/通知许可 → 后台不被关掉 → 麦克风自检）；底部三个标签“今晚 / 睡眠报告 / 我的”；今晚页顶部有“睡前检查”清单；“我的”里随时可重看引导、摆放方法、各品牌后台设置、常见问题。
2. **报告改成看板**：一句大白话结论 + 评分环 + 4 张卡（睡了多久、打鼾、疑似呼吸暂停、睡得稳不稳）+ “夜里发生了什么”时间线 + “最该注意的几件事”+ “和你平时比”+ 可回放的录音 + 最近几晚趋势。专业数字收进“详细数据和说明”。CSV 只留在“我的 > 高级”里，不再是报告功能。
3. **检测改用端侧模型**：纯 Java 实现的 Google YAMNet（521 类，float16 权重 7.5 MB，无原生库），在手机上识别“这是鼾声/呼吸/咳嗽/说话/…”；鼾声必须连成规律的一串才确认；疑似呼吸暂停 = 规律鼾声串里突然安静 10 秒以上且中间没有别的声音。
4. **鼾声时间线重画**：每 10 分钟一根柱子（高度 = 这 10 分钟里打鼾占多少，颜色 = 多响）；上方睡眠状态条；疑似暂停用带编号的菱形、挤在一起时错开；磨牙、咳嗽、说话各有标记；点柱子/菱形/标记可看详情、听录音；“怎么读”说明。磨牙检测加了体动过滤，但仍是实验功能。

## 验证（桌面 JVM，ESC-50 作代理数据，不是真实卧室）
- 分钟级鼾声 100% 检出；剩余误报：呼吸声 42%、喝水声 17%、吱呀声 17%（单段）。
- 合成“鼾声串 + 静默”：≥14 秒的暂停召回约 65%，误报约 0–4%。
- 磨牙：没有真实磨牙录音，代理数据不可靠，未验证。
- 界面：Playwright 里用真实 Java 生成的数据预览 + 交互测试（引导、时间线点选、播放、打卡、设置、各种报告场景），无脚本报错。

## 未验证（没有真机/模拟器）
- WebView 外壳在真机上的表现、各品牌后台策略下整晚存活情况、不同手机麦克风增益下的检测效果、模型在手机上的实际耗时与耗电。
- 很闷的低频鼾声可能被模型漏掉（YAMNet 梅尔频谱从 125 Hz 起）。
- 磨牙检测。

## 下一步候选
